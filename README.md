# حكايتي — Hikayati

منصة تحوّل صورة طفلك إلى قصة وفيلم كرتوني متحرك مخصص، مع تركيز على القيم الأخلاقية.

## الأسعار

- قصة كتاب: **50 درهم** / قصة
- فيلم كرتون: **80 درهم** / فيلم
- باقات شهرية وباقة للمدارس (راجع صفحة الأسعار)

## Stack

- Astro 5 + React 19
- Tailwind CSS 4
- Netlify adapter (SSR)

## Development

```bash
npm install
npm run dev
```

الموقع على `http://localhost:4321`

## Build

```bash
npm run build
```

## الصفحات

- `/` — الرئيسية (Hero بالصورة الحقيقية → الكرتون)
- `/how-it-works` — آلية العمل في ٣ خطوات
- `/stories` — القيم والفئة المستهدفة
- `/library` — مكتبة القصص الجاهزة
- `/pricing` — الأسعار والباقات
- `/create` — معالج إنشاء القصة + الدفع

## API

- `POST /api/checkout` — إنشاء طلب دفع بعد التحقق من المبلغ حسب نوع المنتج.
